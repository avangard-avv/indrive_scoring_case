# AgroScore AI — Система меритократического скоринга сельхозпроизводителей РК

Проект разработан в рамках хакатона **Decentrathon 5.0** (Трек: AI inDrive / GovTech).

## 🚀 Проблема
В Казахстане субсидии часто распределяются по принципу "первый подал — первый получил". Это снижает экономическую отдачу от госсредств. Мы предлагаем решение, которое ранжирует заявителей на основе их реальной эффективности и истории деятельности.

## 🛠 Функционал
- **Автоматический парсинг:** Обработка реестров заявок (учет БИН, статусов, сумм и районов).
- **Merit-based Scoring:** Алгоритм, вычисляющий рейтинг надежности и потенциала хозяйства.
- **Explainable AI:** Система не просто дает балл, а объясняет, почему фермер получил именно такую оценку.
- **Аналитика по регионам:** Визуализация распределения средств (напр., область Абай, Жарминский р-н).

## 💻 Технологический стек
- **Python 3.10+**
- **Pandas/Openpyxl** — работа с данными реестров.
- **Scikit-learn** — построение моделей ранжирования.
- **SHAP** — интерпретация решений ИИ.

## 📁 Структура проекта
- `src/parser.py` — модуль очистки и нормализации данных.
- `src/scoring.py` — логика расчета баллов и агрегации по БИН.
- `data/` — примеры входных данных (реестры).
- `notebooks/` — разведочный анализ данных (EDA).
